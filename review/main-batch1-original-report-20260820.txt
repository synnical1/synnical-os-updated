BATCH CHANGES
-------------
1. Continue Watching fully discontinued from active functionality.
   - Removed SynnFlix Continue Watching type/cache/store/merge/remove helpers.
   - Removed Continue Watching rail/card UI.
   - Removed desktop Continue Watching widget/state/event bridge.
   - Removed Continue Watching resume custom event and retry/remount machinery.
   - Removed Continue Watching setting/default/sanitizer field.
   - Removed obsolete Continue Watching-only regression tests.
   - Preserved normal per-media local playback progress, server MediaProgress, watch parties, autoplay, and stable iframe/player URL behavior.
   - Retains one deliberate one-time cleanup call removing stale localStorage key synnflix.continue.v1.
   - Removes stale desktopContinueWatchingWidget / continue-watching layout state without stripping unrelated unknown layout entries.

2. Desktop startup/window behavior.
   - Removed the fallback openPanel(initialPanel) path that could open an app when the desktop had no usable restored windows.
   - Explicit configured startupApps behavior remains intact.
   - Newly opened applications now start maximized.
   - A normal restore rectangle is saved at launch for Restore Down.
   - Existing maximize/minimize/restore/window manager is preserved.

3. Windows-like app-open animation.
   - Added a short opacity/scale/translate open animation.
   - Uses existing --synnical-os-animation-scale.
   - Existing synnical-os-no-animations disables it.
   - prefers-reduced-motion disables it.

4. Profile statistics/message counts.
   - Separated profile statistics visibility from profile.showFriends.
   - New UI key is profile.showStats.
   - Other-user modal respects API stats privacy before displaying message count.
   - Existing API continues to count real non-deleted Message rows. API route itself was not modified.

5. Profile modal dismissal.
   - Existing Radix Dialog open/onOpenChange contract retained and verified structurally; backdrop/Escape dismissal did not need a risky duplicate handler.

6. Staff/role/tag badge sizing.
   - Reduced text/padding/line-height while preserving current role/tag system.

7. Whole-shell Settings/error crash path hardening.
   - Global window error/unhandledrejection hook no longer deliberately throws an async failure into top-level AppShell.
   - Global errors are logged and emitted as diagnostics instead.
   - Existing per-panel ErrorBoundary isolation is preserved.
   - Fixed ErrorBoundary Try Again button white-on-white text.
   - Exact originating Settings action still requires runtime reproduction in preflight; the architectural route that escalated any async rejection into whole-shell failure has been removed.

8. Games error handling + side-panel focus regression.
   - Games now checks Content-Type/status before accepting catalog JSON.
   - Raw HTML/non-JSON service output is no longer surfaced to normal users.
   - Friendly handling added for auth/404/busy/server/invalid-response states.
   - Game focus now applies only while active panel is Games or GeForce NOW, so opening Chat/other panels does not hide Synnical chrome.
   - server.ts, Stratus API implementation, Wisp and private Stratus configuration were not changed.

9. SynnFlix playback stability preservation.
   - Existing stable useMemo player URL / intentional revision-key behavior retained.
   - Normal playback progress continues to be monotonically persisted locally and server-side.
   - Early bogus provider ended events preserve ordinary progress rather than falsely completing playback.

10. Account-scoped connections.
   - No source change required. Existing restored code already uses account-scoped /api/profile/connections and profile API data; focused regression verifies this contract.
