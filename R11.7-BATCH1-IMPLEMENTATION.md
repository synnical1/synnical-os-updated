## Batch 1 feature audit

1. **Snap Groups — implemented/fixed.** Adjacent snapped windows in the same workspace now share a persistent snap-group identity instead of receiving unrelated random IDs. Grouped windows appear as one grouped taskbar entry and can restore/minimize together.
2. **Snap Layout picker — validated existing implementation.** Hovering the maximize control exposes the existing layout picker and choosing a zone performs a real snap.
3. **Aero-style taskbar previews — implemented honestly.** Hovering a taskbar entry shows a shell-level preview card with real app/window identity, group membership, badges/progress and media state. Browser security prevents reliable live pixel capture of arbitrary cross-origin iframe content, so Synnical does not pretend to provide fake live screenshots.
4. **Taskbar thumbnail controls — implemented for Music.** Previous, play/pause and next controls dispatch to the real Music player state. The infrastructure is generic for additional Synnical media apps as their player APIs expose equivalent controls.
5. **Taskbar progress — implemented.** Managed Browser downloads report byte percentage when a content length is available and an honest indeterminate active state otherwise. Synnical-controlled profile/voice uploads publish an indeterminate taskbar upload state until completion.
6. **Taskbar notification badges — implemented/strengthened.** Chat retains its authoritative unread count. Generic per-app badges are now supported for Browser/Games and future Synnical app events, and opening the corresponding app clears its generic badge.
7. **Per-app taskbar jump lists — implemented.** Right-click taskbar entries expose real supported actions such as Browser Home, Chat compose, Files Recycle Bin, Settings sections, and Music playback commands. Unsupported actions are not fabricated.
8. **Pin/unpin apps — validated existing implementation.**
9. **Reorder pinned taskbar apps — validated existing drag-and-drop implementation.**
10. **Taskbar auto-hide — validated existing implementation.**
11. **Taskbar alignment — validated existing centered/left setting.**
12. **Taskbar sizing — implemented.** Small/Medium/Large changes taskbar, buttons and icons. Window creation, maximize, snap, drag/resize bounds and attached flyouts now respect the selected taskbar height instead of a fixed 48 px reserve.
13. **System tray overflow — validated existing implementation.**
14. **Clock seconds toggle — validated existing implementation.**
15. **Multiple clocks/timezones — implemented.** Users can persist up to four additional valid IANA timezones and view them with the system clock surfaces.
16. **Quick calendar agenda — implemented.** The clock/calendar surface loads real pending Synn Bot reminders and scheduled chat messages and displays them in chronological order.
17. **Focus / Do Not Disturb — strengthened.** Existing Focus state now participates in notification delivery filtering rather than acting only as a visual toggle.
18. **Focus sessions — implemented.** Configurable 15/25/30/45/60/90 minute sessions persist their deadline, expose a countdown, enable Focus for the session, can be stopped, and produce an urgent completion notice when finished.
19. **Notification priority levels — implemented.** Normal, priority and urgent notification levels are persisted and used by Focus filtering and notification presentation.
20. **Per-app notification settings — implemented.** Chat, Calls, Browser, Music, Games and SynnFlix have persisted enable/disable and priority rules; the event pipeline enforces them.
21. **Notification history — implemented.** Dismissed/cleared notices can be archived in persistent Synnical notification history, with a user setting to disable the history feature.
22. **Notification grouping by app — implemented.** Current notifications are rendered in app groups rather than an undifferentiated list.
23. **Desktop widgets — real foundation implemented.** Clock and Calendar are real desktop-surface widgets controlled by persisted settings. Custom positioning and resizing are intentionally not claimed here because those are separate backlog items 32 and 33.
24. **Clock widget — implemented.** Shows local clock, optional seconds, date and configured additional clocks on the desktop surface.
25. **Calendar widget — implemented.** Shows the current calendar month on the desktop surface.

## Emergency moderation repair included in Batch 1

During Batch 1 an intentional AutoMod test showed that `ADMIN` and `MOD` accounts could still be permanently auto-banned for prohibited content. The old automatic-ban exemption only covered `OWNER` and `HEAD_ADMIN`.

The repair now:

- keeps prohibited staff messages blocked and audited;
- exempts `MOD`, `ADMIN`, `HEAD_ADMIN` and `OWNER` from **automatic** bans;
- leaves manual moderation hierarchy intact;
- adds a real staff-only unban API with hierarchy checks;
- preserves the original ban record as historical data by revoking permanence rather than deleting history;
- removes identity-ban rows attributable to the restored account;
- recomputes any separate legitimate active mute instead of blindly clearing all moderation state;
- records an `UNBAN` infraction and audit-log event;
- exposes an **Unban** control in the staff account panel for actively banned users.

The production emergency restoration of `@void` was performed separately and successfully before this package was finalized. This source package contains the permanent product-side fix so the same automatic-staff-ban failure does not recur.

## Important implementation details

- OS settings continue to use the existing account-backed `/api/features/os` persistence path. New Batch 1 settings are sanitized and synced rather than scattered into unrelated one-off storage writes.
- Synnical OS notifications now receive relevant incoming Chat, Browser download and Games events, so the notification centre, grouping, history and Focus rules operate on real events.
- Music publishes actual media state and accepts actual taskbar media commands.
- Snap-group construction is based on adjacent snapped window geometry within the active workspace.
- Taskbar sizing is used by usable desktop geometry, not just CSS cosmetics.
